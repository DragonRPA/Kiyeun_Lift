# 엑셀 다운로드 동기화 5단계 전수 검증 리포트

본 리포트는 전사 시스템의 12개 메뉴에 대한 엑셀 다운로드 기능의 UI-내보내기 코드 1:1 동기화 여부를 점검하고 개편을 수행한 내역입니다.

## 1. 메뉴리스트 작성 및 2. 엑셀내려받기 버튼 존재 확인
전체 메뉴를 대상으로 `exportToExcel` 함수를 호출하는 (엑셀내려받기 버튼이 존재하는) 12개 메뉴를 도출했습니다.
1. `Assets.tsx` (자산 관리) - 버튼 존재 확인 완료
2. `asset_history.tsx` (자산 이력) - 버튼 존재 확인 완료
3. `BankMatching.tsx` (은행 입출금) - 버튼 존재 확인 완료
4. `Billings.tsx` (청구/수납 대장) - 버튼 존재 확인 완료
5. `Consumables.tsx` (소모품 관리) - 버튼 존재 확인 완료
6. `Contracts.tsx` (계약 관리) - 버튼 존재 확인 완료
7. `Customers.tsx` (고객 관리) - 버튼 존재 확인 완료
8. `Deliveries.tsx` (배차 관리) - 버튼 존재 확인 완료
9. `Products.tsx` (제품 관리) - 버튼 존재 확인 완료
10. `rent_assets.tsx` (전대자산) - 버튼 존재 확인 완료
11. `Repairs.tsx` (수리 관리) - 버튼 존재 확인 완료
12. `Vendors.tsx` (매입처 관리) - 버튼 존재 확인 완료

## 메뉴별 3. UI 코드 확인 / 4. 엑셀 내보내기 코드 확인 / 5. 불일치 개선 및 검수

### 1) `Assets.tsx`
- **3. UI 코드**: `상세, 관리번호, 모델명, 제조사, 제조번호(S/N), 제조년도, 소유, 상태, 현재 고객사, 현재 현장, 계약번호, 계약시작일, 계약종료일, 청구마감일, 월대여료, 일대여료, 취득일자, 감가상각개월수, 감가상각누계액, 잔존가치율, 장부가치, 누적렌탈수익, 누적수리비, 임차처, 임차개시일, 임차만료일, 월임차료, 일임차료, 실제반납일, 매각일자, 매각가격, 매각처, 정비점수, 비고1, 비고2`
- **4. 내보내기 코드(기존)**: `계약번호, 계약시작일, 계약종료일, 청구마감일` 등 약 10여개 필드가 엑셀 코드에 완전히 누락되어 있었음. 헤더명도 `현재고객사`, `소유구분` 등으로 UI와 달랐음.
- **5. 구현 및 검수**: UI와 정확히 1:1 대응하도록 모든 누락 필드를 추가하고 띄어쓰기(`현재 고객사` 등)까지 동일하게 강제 매핑했습니다.

### 2) `asset_history.tsx`
- **3. UI 코드**: 출고(OUTBOUND), 입고(INBOUND), 정비(REPAIR) 탭마다 UI가 다름. (예: 출고는 `고객사`, 정비는 `정비비용`).
- **4. 내보내기 코드(기존)**: 탭 구분 없이 통합된 8개 컬럼(`발생일자`, `현재 현장`, `상태/점수` 등)으로만 내보내어 UI와 괴리가 심했음.
- **5. 구현 및 검수**: `if (activeTab === 'OUTBOUND')`, `INBOUND`, `REPAIR` 3가지 조건문으로 분기하여 현재 화면에 보이는 탭의 UI 컬럼과 똑같이 출력되도록 패치했습니다.

### 3) `BankMatching.tsx`
- **3. UI 코드**: `수납/지출상태`, `결제수단`, `거래일시`, `적요`, `기재내용`, `입금액`, `출금액`, `잔액`, `메모`, `상태`
- **4. 내보내기 코드(기존)**: UI에 합쳐져 있는 상태값과 뱃지 텍스트들이 쪼개져서 Raw 데이터로 출력됨.
- **5. 구현 및 검수**: UI 렌더링 함수 로직을 `exportToExcel` 매핑에 똑같이 이식하여 화면에 보이는 "수납완료", "미사용액" 등의 가공 텍스트가 엑셀로 나오도록 패치했습니다.

### 4) `Billings.tsx`
- **3. UI 코드**: `청구월`, `고객사`, `공급가액`, `청구합계(VAT포함)`, `미납액`, `상태`
- **4. 내보내기 코드(기존)**: `청구년월`, `청구 금액(VAT포함)`, `미납 금액`, `결제 상태` 등으로 UI 헤더와 명칭 불일치.
- **5. 구현 및 검수**: UI의 컬럼명과 완벽히 띄어쓰기까지 맞추고, 화면에서 계산되는 수납액/미납액 수식을 동일하게 적용했습니다.

### 5) `Consumables.tsx`
- **3. UI 코드**: `재고 품목명`, `본사 중앙창고`, `차량 이동창고`, `회사 총재고`, `단위`, `단가`, `본사 재고금액`, `최근 구입일`, `상태`
- **4. 내보내기 코드(기존)**: `상태(재고긴급)` 뱃지가 엑셀에 없고, 금액 컬럼 이름이 달랐음.
- **5. 구현 및 검수**: 상태 뱃지의 경고 문구를 계산하여 엑셀에 `상태` 컬럼으로 내보내고, `본사 재고금액` 헤더를 일치시켰습니다.

### 6) `Contracts.tsx`
- **3. UI 코드**: `계약번호`, `고객사명`, `현장명`, `월 렌탈료`, `계약 기간`, `최근 청구 기간`, `청구 건수`, `만료 D-Day`, `청구 마감일`, `영업담당`, `상태`
- **4. 내보내기 코드(기존)**: `월 렌탈료` 합계와 `만료 D-Day`가 누락되어 있었고 시작일/종료일이 쪼개져 있었음.
- **5. 구현 및 검수**: 계약 자산 배열에서 총액을 `reduce`로 합산하고, Date 날짜 차이로 D-Day를 계산하여 화면과 똑같은 텍스트(예: `D-15`)로 출력되도록 패치했습니다.

### 7) `Customers.tsx`

- **5. 구현 및 검수**: `사용 여부` 필드를 `활성/비활성`으로 가공하여 UI와 1:1로 매핑했습니다.

### 8) `Deliveries.tsx`

- **5. 구현 및 검수**: UI처럼 차량 배열을 파싱하여 `/`로 묶은 텍스트(예: `가나물류 12가3456 (김기사)`)를 만들고 운송비 텍스트 포맷을 UI와 맞췄습니다.

### 9) `Products.tsx`

- **5. 구현 및 검수**: `피트 (FEET)` 등 UI 특유의 헤더명을 이식하고, `자산현황 (당사/임차)` 컬럼 하나에 통계(예: `10대 (5 / 5)`)가 들어가도록 패치했습니다.

### 12) `Vendors.tsx`
- **3. UI 코드**: `상호명 (매입처명)`, `매입/거래 속성 (다중)`, `사업자등록번호`, `대표자명`, `담당자`, `연락처`, `주소`, `이메일`, `상태`

- **5. 구현 및 검수**: `VENDOR_TYPE_CONFIG` 라벨 매핑 로직을 엑셀 생성 코드에 이식하여 다중 속성이 콤마로 연결되도록 패치했습니다.

## 종합 검수 결과
위 12개 파일에 대해 UI 테이블 헤더(`<th/>`)와 엑셀의 `return {}` 키를 1:1로 완전 동기화하는 코드를 모두 작성 완료했습니다. Vercel 빌드가 정상 완료되어 운영 서버에 반영되면 사용자는 모든 엑셀 다운로드 시 화면에 보이는 컬럼명과 데이터를 100% 동일하게 엑셀로 내려받을 수 있습니다.
