# 감사 리포트 디렉토리 (audit_reports/)

## 관리 규칙
- **파일 명명**: `YYYY-MM-DD_audit.md` (일 1회 기준, 같은 날 재실행 시 덮어씀)
- **보존 정책**: 전체 이력 영구 보존 (삭제 금지)
- **갱신 주기**: 기능 개편 완료 시, 또는 명시적 점검 요청 시 즉시 생성
- **자동 스크립트 산출물**: `scripts/audit.ts` 실행 결과는 프로젝트 루트 `audit_report.md`에 별도 저장됨 (이 폴더와 무관)
