## 3. 감점 원인 상세 기재 (-5점)

1. **CI/CD 파이프라인 내 WTT 스위트 자동 실행 미결합 (-3점)**:
   - 금일 구축된 16대 업무활동 WTT 종합 스위트(`wtt_full_business_activity_suite.cjs`)가 수동 CLI 실행 및 배포 전 검증 스크립트로 동작하고 있으나, GitHub Actions의 `push` 이벤트 시 자동 실행되는 CI 파이프라인에 아직 등록되지 않아 개발자의 수동 실행에 의존하고 있는 점.
2. **번들링 시 500kB 초과 청크 및 pdfjs-dist require 경고 잔존 (-2점)**:
   - `npm run build` 결과 1.27초로 빌드는 정상 통과하나, `pdfjs-dist` 라이브러리의 eval require 경고 및 5MB 단일 벤더 번들 경고가 남아 있어 대규모 현장 모바일 환경에서의 초기 로딩 성능 최적화가 추가로 요구됨.
