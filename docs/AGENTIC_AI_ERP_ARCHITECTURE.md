# 에이전틱 AI (Agentic AI) ERP 운용 체계 및 도메인 가드레일 아키텍처 명세서 (Agent-Native ERP Specification)

- **버전**: v1.0.0
- **제정일시**: 2026-09-12
- **시스템**: 기연리프트 ERP (e-Bro ERP System)
- **적용 대상**: Claude Cowork, OpenAI Operator, OSWorld, 로컬 ReAct Agent 및 사내 AI 비서 파이프라인

## 1. 배경 및 문제 제기 (Executive Background)

### 1.1 왜 전통적 웹 자동화/비전 에이전트는 ERP에서 실패하는가?
1. **GUI 렌더링 및 타이밍 취약성**:
   - 웹 ERP는 수십 개의 모달, 탭, 드롭다운, 다이나믹 뷰포트 및 반응형 스타일이 복합 작동함.
   - Claude Computer Use나 Playwright 픽셀 기반 에이전트는 해상도 변화, 스크롤 오프셋, 모달 애니메이션 딜레이로 인해 실패율이 30~50%에 달함.
2. **비즈니스 도메인 불변식 파괴 위험**:
   - 에이전트가 데이터베이스에 직접 SQL로 INSERT/UPDATE를 수행할 경우:
     - 출고 검수 승인 시 `RENTED` 전환 누락 (전사 표준 헌장 1.3 위반)
     - 대차/교체 시 편도 배차 2건으로 분할 발행 (전사 표준 헌장 2.3 위반)
     - 대차 전/후 자산 일할 매출 기여액 불일치 (전사 표준 헌장 4.1 위반)
     - 이로 인해 전사 회계 및 자산 상태의 무결성이 치명적으로 훼손됨.

### 1.2 패러다임 전환: Agent-Friendly를 넘어 Agent-Native로
- 인간에게는 아름다운 고밀도 반응형 GUI를 제공하고,
- AI 에이전트에게는 **0ms 만에 100% 신뢰성으로 작동하는 의미론적(Semantic) 도구 호출 인터페이스와 헌장 가드레일**을 제공한다.

## 3. 계층별 상세 규격

### 3.1 [L1] 기계 판독형 카탈로그
- **파일**: `AGENTS.md` (루트) 및 `src/services/agenticActionGateway.ts`
- LLM의 컨텍스트 윈도우 효율을 극대화하기 위해 불필요한 설명 없이 **오직 건조한 명사 구조(테이블명, 컬럼, 타입, 필수 여부, 외래키, 허용 상태값 enum)**만을 제공.

### 3.2 [L2] 시맨틱 액션 툴 20선 (MCP 규격)
| 도메인 | 도구 식별자 (`name`) | 설명 | 헌장 연계 |
|:---|:---|:---|:---|
| **배차/물류** | `dispatch_create_exchange` | 단일 EXCHANGE 왕복 배차 발행 및 왕복할인 자동 계산 | 헌장 2.3 |
| **배차/물류** | `dispatch_create_outbound` | 편도 출고 배차 의뢰 등록 | 헌장 1.2 |
| **배차/물류** | `dispatch_create_inbound` | 편도 회수 배차 의뢰 등록 | 헌장 1.2 |
| **배차/물류** | `dispatch_cancel_order` | 배차 취소 (자산 상태 비조작 보존) | 헌장 1.3 |
| **입출고/검수** | `inspection_approve_outbound`| 출고 검수 승인 및 자산 RENTED 전환 | 헌장 1.3 |
| **입출고/검수** | `inspection_reject_outbound` | 검수 불합격 및 REPAIRING 격리 | 헌장 1.2 |
| **영업/계약** | `contract_exchange_asset` | 대차 자산 계약 속성 100% 자동 상속 및 일할 매출 계산 | 헌장 2.2, 4.1 |
| **영업/고객** | `customer_bulk_create` | 고객사/현장/담당자 1:N 구조 일괄 생성 | 헌장 1.1 |
| **영업/채권** | `delinquency_block_customer` | 연체 고객사 출고 차단 (`BLOCKED`) | 헌장 1.2 |
| **정비/소모품** | `consumable_bulk_purchase` | 소모품 대량 매입 및 재고 가산 | 헌장 1.2 |
| **정비/소모품** | `consumable_field_use` | 현장 수리 부품 차감 및 수불로그 적재 | 헌장 1.2 |
| **정비/수리** | `repair_complete_maintenance`| 정비 완료 보고, AVAILABLE 복원, 점수 0점 | 헌장 5.5 |
| **경영/통장** | `bank_match_deposit` | 통장 입금 1:1 매칭 및 수수료 보정 (차액 ₩0) | 헌장 3.5, 5.5 |
| **경영/차량** | `vehicle_log_fuel` | 법인차량 주유 명세서 등록 및 누적거리 갱신 | 헌장 1.2 |
| **시스템/감사** | `system_verify_charter_invariants`| 날짜·수지·상태 3대 보존 법칙 전수 감사 | 헌장 5.5 |

### 3.3 [L3] 헌장 불변식 가드레일 (Charter Guardrails)
- AI 에이전트의 환각(Hallucination)이나 도메인 규칙 미숙지를 원천 방어:
  - **가드레일 1**: 대차 배차를 출고/회수 2건으로 분할 요청 시 즉시 차단 (`GUARDRAIL_BLOCKED`).
  - **가드레일 2**: 출고 검수 완료 시 상태값을 `RENTED` 이외의 값으로 지정할 수 없음.
  - **가드레일 3**: 음수 단가, 음수 수량, 대차대조 차액 발생 시 즉시 롤백 및 거부.
