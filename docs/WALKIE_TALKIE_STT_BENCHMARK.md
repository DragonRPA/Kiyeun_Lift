## 1. STT 엔진 도입 배경 및 기술적 요구조건

1. **초저지연 (Sub-second Latency)**: 무전기는 실시간 통신이므로 발언 종료 후 1초 이내에 자막이 화면에 표출되어야 함.
2. **모바일 안정성 (Mobile Resilience)**: 안드로이드(삼성 갤럭시 S24 등) 및 iOS 사파리 환경에서 마이크 하드웨어 점유 충돌(`AudioRecord` 오류) 없이 백그라운드 웹소켓 수신과 동시 구동되어야 함.
3. **도메인 한국어 정확도 (Domain Korean Accuracy)**: "지에스 일구삼공", "판교 현장", "과상승 감지봉", "협착 방지봉" 등 고소작업대 렌탈 특화 전문 용어 및 모델명의 정확한 전사.
4. **운영 비용 0원 (Zero External Cost)**: 수백 명의 임직원이 하루 수천 번 무전 및 음성 지시를 주고받아도 API 과금 폭탄 위험이 없는 지속 가능한 인프라.

## 3. 엔진별 상세 테스트 과정 및 불채택 사유

### (1) Web Speech API (브라우저 내장 STT)
- **테스트 내용**: 브라우저의 `webkitSpeechRecognition`을 사용하여 별도 백엔드 서버 없이 클라이언트에서 즉시 텍스트 변환 시도.
- **불채택 사유**:
  1. **안드로이드 HAL 마이크 독점 충돌**: 무전기는 음성 바이너리 전송을 위해 `MediaRecorder`를 구동하는데, 안드로이드 크롬에서는 `SpeechRecognition`과 `MediaRecorder`가 오디오 하드웨어 스트림을 동시 점유할 수 없어 `AudioRecord start failed` 크래시 발생.
  2. **어휘 제어 불가**: 브라우저 제조사(구글) 서버의 기본 사전에만 의존하므로, 고소작업대 모델명("GS-1930", "SJ-3219")이나 현장 전문 용어를 학습시키거나 프롬프트로 바인딩할 수 없음.
  3. **PWA 백그라운드 침묵**: 모바일 PWA 환경에서 화면이 잠시 꺼지거나 백그라운드로 가면 음성인식이 강제 종료됨.

### (2) Gemini 2.0 Flash STT (Google AI REST API)
- **테스트 내용**: 녹음된 오디오 바이너리를 base64로 인코딩하여 Gemini Flash 멀티모달 API로 전송, 텍스트 전사 및 도메인 파싱 동시 시도 (`api/gemini-stt.ts`).
- **불채택 사유**:
  1. **높은 지연 시간 (2.5초 ~ 4.2초)**: 멀티모달 LLM 특성상 오디오 디코딩 후 텍스트 토큰 생성까지 3초 내외가 소요되어 PTT 무전 통신의 실시간성을 저해함.
  2. **외부 과금 및 쿼터 차단 리스크**: 무전 대화량이 늘어날 경우 분당 15RPM 무료 쿼터를 즉각 초과하여 429 에러가 발생하거나 종량제 과금 폭탄 위험 상존.

### (3) Cloudflare Workers AI Whisper (`@cf/openai/whisper`)
- **테스트 내용**: 사내 Cloudflare R2 인프라와 결합하여 Workers AI Whisper 엔드포인트를 구축하고, 하루 10,000 뉴런 무료 쿼터를 활용한 서버리스 STT 운영 (`api/cf-stt.ts`).
- **불채택 사유**:
  1. **극심한 콜드스타트 지연 (11.37초)**: 유휴(Idle) 상태에서 첫 무전 발생 시 Cloudflare 공유 GPU 컨테이너 프로비저닝 및 VRAM 모델 가중치 로딩에만 7~8초 이상 소요되어 총 11초 이상의 응답 지연 발생.
  2. **Vercel-Cloudflare 이중 서버리스 홉(Hop)**: 모바일 단말 ➔ Vercel Serverless Function ➔ Cloudflare Workers AI ➔ Vercel ➔ 모바일의 4단계 네트워크 왕복 오버헤드.
  3. **바이너리 컨테이너 단편화**: `MediaRecorder`의 타임슬라이스 청크가 WebM EBML 헤더를 불완전하게 생성할 경우 Cloudflare 모델이 오디오 길이를 0초로 오인하여 빈 문자열 반환.

### (4) Groq LPU Whisper Large-v3-Turbo (경량화 4레이어)
- **테스트 내용**: Groq의 언어 처리 전용 하드웨어 칩셋(LPU)을 활용하여 초고속 전사를 구현하고자 `whisper-large-v3-turbo` 모델 연동.
- **실측 성과**: 응답 속도 **0.33초**로 세계 최고 수준의 하드웨어 가속 달성.
- **불채택 사유 (영어 편향 및 번역 환각)**:
  - 4개 디코더 레이어로 경량화된 `turbo` 모델은 모바일 환경의 저비트레이트 Opus 압축 음성이나 잡음이 섞인 한국어를 입력받았을 때, 한국어 전사 대신 **영어 번역을 시도하거나 영어 알파벳으로 왜곡 출력**하는 치명적 결함 발생 (예: "내일 아침 1930 두 대요" ➔ "Tomorrow morning...").

## 4. 최종 채택: Groq LPU Whisper Large-v3 (풀사이즈 32레이어)

### 선정 사유 및 기술적 완성
1. **0.35초대 초고속 지연시간 유지**:
   - 32개 디코더 레이어를 가진 풀사이즈 원본 대형 모델임에도, Groq LPU 하드웨어 가속 덕분에 **0.35초(350ms)** 만에 완전한 전사 결과를 반환.
2. **한글 토큰 앵커링(Context Conditioning) 및 환각 원천 차단**:
   - Groq API 호출 시 `prompt: '기연리프트 무전 통신.'`을 주입하여 디코더의 초기 어휘 공간을 한국어로 강제 고정.
   - `temperature: '0'` 설정을 통해 샘플링 분산을 0으로 만들어 영어 번역 이탈 및 환각 현상을 100% 차단.
3. **32kbps 모노 음성 최적화**:
   - 오디오 녹음 시 무리한 16kHz 다운샘플링 왜곡을 제거하고 네이티브 샘플링 + 32kbps Opus 압축을 적용하여 한국어 자음/모음 음소를 선명하게 보존.
4. **비용 0원 및 넉넉한 쿼터**:
   - Groq 공식 무료 티어 기준 하루 7,200회 요청, 분당 30RPM을 제공하여 사내 전사 무전 트래픽을 외부 비용 0원으로 완벽 수용.
